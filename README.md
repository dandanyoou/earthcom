# Culture·Bridge — 지구 → 마을 탐색 (최종본)

업로드하신 프로토타입(`culturebridgeglobeprototype.html`)을 기반으로 정리한 단일 파일 데모입니다.
생성해두신 PNG 7장이 그대로 붙어 있고, 빌드 과정은 없습니다.

## 실행

```bash
bash download-assets.sh   # images/ 에 PNG 7장 (선택)
open index.html
```

`download-assets.sh`를 건너뛰어도 열립니다. **로컬 파일이 없으면 CDN 원본으로 자동 대체**되기 때문에,
`index.html` 하나만 옮겨도 동작합니다. 오프라인 데모(심사장 와이파이 등)라면 스크립트를 먼저 돌려두세요.

## 화면이 비어 보일 때

이미지가 한 장도 안 붙으면 지구본도 마을도 안 보입니다. 그때는 페이지가 **직접 알려주고, 그 자리에서 고칠 수 있게** 되어 있습니다.
각 자리에 `지구 이미지 없음` 같은 회색 플레이스홀더가 뜨고, 하단에 안내 패널이 나옵니다. 두 가지 중 하나로 해결하세요.

1. **터미널** — `bash download-assets.sh`
2. **끌어다 놓기** — 채팅에서 받은 PNG 7장을 브라우저 창에 그대로 드롭하거나 `파일 선택`으로 고르면 즉시 붙습니다.
   파일명(`village-kr.png`)이든 다운로드 원본명(`hf_...45a0844d....png`)이든 이름으로 자동 배치됩니다. 네트워크가 필요 없습니다.

## 프로토타입에서 바뀐 것

**1. 마커를 퍼센트에서 위경도 정사영으로 교체**

전에는 `x:56, y:40` 처럼 이미지 위 퍼센트를 눈으로 맞춰야 했고, README에도 "바로 손봐야 할 것"으로
적혀 있었습니다. 이제 각 나라는 실제 위경도를 갖고, 구면에 정사영해서 화면 좌표를 계산합니다.

```js
{ id:"kr", name:"대한민국", lat:37.57, lon:126.98 }
const GLOBE_VIEW = { cx:50, cy:50, r:44, lon0:132, lat0:14 };
```

조정할 값이 나라 6개 × 2개에서 **전역 5개**로 줄었고, 지구 반대편 나라는 자동으로 숨습니다.
지구 렌더가 동아시아를 정면으로 보고 있어서 한국·베트남·인도만 구면에 찍히고,
독일·브라질·미국은 하단 레일에 `뒷면` 표시로 남습니다 — 전부 클릭은 됩니다.

보정이 필요하면 브라우저에서 **`G` 키**를 누르세요. 슬라이더로 중심·반지름·시선 경위도를 실시간으로
움직이고, 패널 아래에 붙여넣을 `GLOBE_VIEW` 한 줄이 나옵니다.

**2. 마을 6곳을 하나의 이어진 세계로**

전에는 마을마다 사진 한 장을 크로스페이드했습니다. 이제 6장이 **하나의 가로 스트립**에 놓이고,
카메라(스트립 전체의 transform 하나)가 그 위를 움직입니다. 마을 이동은 컷이 아니라 이동입니다.

- 마을 안: `scale 1.12`로 들어가 있음
- 이동: 위로 뜨면서 `scale 0.46`까지 빠짐 → 옆 마을이 같이 보임 → 다시 내리꽂음

빠져나온 순간에는 각 마을이 **모서리 둥근 떠 있는 섬**으로 바뀝니다. 프롬프트에 넣으셨던
`soft-edged floating island`를 화면에서도 그대로 살린 부분입니다.

뒤로 빠졌을 때 위아래에 검은 띠가 생기지 않도록, 뒤쪽에 하늘 그라디언트 + 현재 마을 이미지를
크게 블러한 대기층을 깔았습니다. 축소가 "사진이 작아지는 것"이 아니라 "고도가 올라가는 것"으로 읽힙니다.

**3. 이미지 확대·축소를 자연스럽게**

- 패널이 렌더 원본과 같은 **16:9**를 유지합니다. 레이아웃이 이미지를 늘리거나 자르지 않고,
  잘리는 건 카메라가 밀고 들어갈 때뿐입니다.
- 최대 확대를 `1.12`로 잡았습니다. 마을 5장이 1344×768이라 이 이상 밀면 뭉갬이 보입니다.
  (한국 컷만 2752×1536이라 여유가 있습니다.)
- 각 이미지에 26초 주기의 아주 느린 호흡(`scale 1.015 → 1.06`)을 걸어 정지 화면처럼 보이지 않게 했습니다.
- 패널 좌우 가장자리를 페더링해서 옆 마을과 이어 붙였습니다.
- 상·하단 틸트시프트 밴드를 CSS로 한 번 더 얹어, 카메라가 축소돼도 미니어처 톤이 유지됩니다.

**4. 조작**

| | |
|---|---|
| 마커 / 하단 카드 클릭 | 그 나라로 다이브 |
| `←` `→` | 옆 마을로 비행 |
| 스크롤 · 스와이프 | 옆 마을로 비행 |
| 우측 점 레일 | 임의의 마을로 점프 |
| `Esc` / `← 지구로` | 지구로 복귀 |
| `G` | 지구본 보정 패널 |

**5. 고친 버그 (프로토타입에 있던 것)**

- 마을 화면에서 투명해진 상단바가 클릭을 가로채 **`← 지구로` 버튼이 안 눌리던** 문제
  (`opacity:0`만으로는 히트 영역이 남습니다 → `pointer-events:none` 추가)
- `.marker`의 `display:flex`가 `[hidden]`을 이겨서 **뒷면 나라 마커가 거울처럼 앞면에 찍히던** 문제
- 지구로 돌아올 때 `hidden` 해제와 클래스 제거가 한 프레임에 합쳐져 **줌아웃이 재생되지 않던** 문제
- 이미지 로드가 실패해도 **아무 안내 없이 검은 화면만 나오던** 문제 (깨진 `<img>`는 아무것도 그리지 않습니다)

## 아직 더미인 것

- 모임 수·시간대는 전부 더미입니다. 백엔드 집계 API가 붙으면 `COUNTRIES` 배열만 응답으로 교체하면 됩니다.
- 마을 카드를 누르면 모임 상세로 넘어가지 않고 자리 표시만 바뀝니다.
- 일본은 이미지 생성이 실패해 빠져 있습니다. 명세 §8-2의 5개국 기준에서는 일본 자리에 브라질·인도가 들어간 형태입니다.

## 이미지 품질에 대해

마을 5장(미국·독일·베트남·브라질·인도)은 `nano_banana`, 한국만 `nano_banana_2` 2K입니다.
톤과 디테일이 눈에 띄게 차이 납니다. 심사·데모용이면 나머지 5장을 같은 프롬프트로 `nano_banana_2`에서
다시 뽑는 걸 권합니다. 파일명만 유지하면 교체는 그대로 반영됩니다.

## Next.js 앱으로 옮길 때

이 데모의 스트립 카메라는 `frame(i, s)` 함수 하나로 표현돼 있습니다 — 패널 인덱스와 배율을 받아
`translate3d + scale`을 돌려주는 순수 함수라, 컴포넌트로 옮길 때 그대로 가져가면 됩니다.
지구만 `react-globe.gl`로 바꾸고 마커 클릭에 같은 전환을 물리면 명세 §9의 1·2순위가 채워집니다.
